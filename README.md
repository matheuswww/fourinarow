# Four in a Row

**Four in a Row** is an online and interactive version of the classic board game, where the objective is to align four pieces of the same color, either vertically, horizontally, or diagonally. Developed with **Golang** on the backend and **Next.js**

- **Docker**: The application is containerized with **Docker** for easy setup and deployment.
- **Kubernetes**: The application is orchestrated using **Kubernetes**.
